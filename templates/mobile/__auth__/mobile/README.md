# {{ context.app_name }} mobile

Expo/React Native application with `expo-auth-session` authorization-code + PKCE authentication, generated by Baukit template {{ context.template_version }}.

Run the composed Keycloak, copy `.env.example` to `.env`, then run `corepack pnpm@11.18.0 install --frozen-lockfile && corepack pnpm@11.18.0 start`. Sign in with `test` / `password`. Tokens are kept in Expo SecureStore, refreshed before expiry, and cleared before Keycloak logout. Physical devices must use one reachable hostname consistently for both API and issuer URLs; the composed HTTP issuer is for emulator/local development only, and production must use HTTPS.

The Baukit packages come from {{ context.baukit_typescript_dependency_description }} and the generated lockfile makes the first install reproducible. Native compilation is outside the portable CI gates; run `corepack pnpm@11.18.0 typecheck`, `corepack pnpm@11.18.0 lint`, and `corepack pnpm@11.18.0 test`.
