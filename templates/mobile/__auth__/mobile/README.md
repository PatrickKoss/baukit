# {{ context.app_name }} mobile

Expo/React Native application using the provider-neutral `@baukit/auth-native` authorization-code + PKCE lifecycle with thin Expo adapters, generated by Baukit template {{ context.template_version }}.

Run the composed Keycloak, copy `.env.example` to `.env`, then run `corepack pnpm@11.18.0 install --frozen-lockfile && corepack pnpm@11.18.0 start`. Sign in with `test` / `password`. Standard OIDC discovery supplies authorization, token, UserInfo, and optional end-session endpoints. The authenticated UserInfo `sub` is exposed independently from the backend's internal user ID. Tokens are kept in Expo SecureStore and refreshed before expiry. This template deliberately opts into `offline_access`; remove `offlineAccess: true` if the deployed provider does not issue offline refresh tokens.

Authenticated startup resolves the immutable OIDC subject before opening the subject's opaque SQLite database or enabling user-scoped API/cache/analytics work. Account changes close SQLite and reset memory first; terminal session expiry closes and blocks rather than masquerading as an account switch. The generated logout policy is **retain**. Review [docs/local-data-retention.md](docs/local-data-retention.md) before changing it.

Protected API calls use the runtime's explicit one-replay 401 handshake: concurrent callers share refresh, terminal refresh rejection clears the session and announces expiry, while transient provider/network failure preserves it for a later retry. A second 401 stops. Automatic replay does not make writes idempotent; write endpoints still need a server-side idempotency contract.

Local state is cleared before provider logout. If provider logout is unavailable or fails, the next sign-in forces `prompt=login`. Cancel and dismiss results are non-errors and are announced so product UI can restore focus or provide additional guidance. Physical devices must use one reachable hostname consistently for both API and issuer URLs; the composed HTTP issuer is for emulator/local development only, and production must use HTTPS.

The Baukit packages come from {{ context.baukit_typescript_dependency_description }} and the generated lockfile makes the first install reproducible. Native compilation is outside the portable CI gates; run `corepack pnpm@11.18.0 typecheck`, `corepack pnpm@11.18.0 lint`, and `corepack pnpm@11.18.0 test`.
